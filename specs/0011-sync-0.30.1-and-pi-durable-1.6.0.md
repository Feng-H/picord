# Spec 0011: Sync `upstream/main` (`v0.30.1`) & `@earendil-works/pi-durable` `1.6.0`

- **Status**: Implemented
- **Preceded By**: [specs/0010-deepen-voice-module.md](./0010-deepen-voice-module.md)

## Problem Statement
After completing all four pre-merge codebase-deepening candidates (`1 → 3 → 4 → 2`), `Feng-H/picord` needed to merge `upstream/main` (`TannerMidd/pi-pocket` `v0.30.1`, commit `8892071f`) and upgrade `@earendil-works/*` from `1.5.2` to `1.6.0` while preserving Picord's architectural boundaries (username/password auth, multi-user `TurnPipeline` steering guard, `DialogueRuntime` coordinator, ADR-0006 `EventConnection` transport engine, and permanent `Relay` bridge exclusion).

## Solution
Merge `upstream/main` (`8892071f`) on `sync/0.30.1` with targeted boundary integrations and fixes verified by two-axis code review:
1. **Dependencies & Tooling**: Align all `@earendil-works/*` packages (`chord`, `pi-ai`, `pi-codemode`, `pi-coding-agent`, `pi-durable`, `pi-mcp`, `pi-schema`) to `1.6.0` and bump `picord` version to `0.30.1`. Preserve `check:sandbox` and `--test-timeout=600000` in `package.json`.
2. **Auth & Sign-In (`src/server/auth.ts`, `src/server/http/sign-in.ts`)**: Keep Picord password auth (`verifyCredentials`, `redeemWithPassword`, `/register`) alongside `0.30.1` desktop one-time links (`createSignInLink`, `redeemSignInLink`, `?once=`) and `?token=` account-switch prompt; handle spent/expired `once` on both `GET` and `POST` with HTTP `401` and normalize `/register` usernames identically to `auth.ts`.
3. **TurnPipeline + TurnNotes (`src/server/turn-pipeline/*`, `src/server/commands.ts`)**: Pass transcribed speech (`media.said`) through `dispatchDurable` into `#submitInput(...)` so upstream `TurnNotes` (`app.turnNotes`) annotates non-interrupt, non-queued turns including audio-only voice messages, while keeping `MediaProcessor` + `SteeringPolicy` (`activeTurnAuthorId` guard).
4. **Transport Engine & Service Worker (`web/connection.js`, `web/store.js`, `web/sw.js`)**: Retain ADR-0006 `EventConnection` across `web/store.js` while fixing `0.30.1` alignment gaps — remove orphaned `handlers.switched` in `web/store.js`, forward all 28 SSE events in `web/connection.js`, add `FIRST_DATA_MS` (`10_000`), `quietStreams >= 2`, `POLL_FOR_MS` (`24h`), per-session `settles`, `readyState === CLOSED` `onerror` handling, and `pollStallMs(hold)` abort watchdogs; bump `SHELL_CACHE` to `picord-shell-v9` with `/connection.js` cached.
5. **Relay Exclusion & Docs**: Keep `pocket-relay*`, `test/relay*.test.ts`, and `docs/extensions/relay.md` removed; fix broken `README.md` doc anchors (`docs/running.md`, `docs/features.md`, `SECURITY.md`), remove stale relay mention in `docs/extensions/turn-notes.md`, and fix `site/index.html` footer link (`durable.html`).
