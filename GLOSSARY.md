# Picord Domain Glossary

A self-hosted, Discord-style personal Agent runtime built on Pi.

## Channels

**Channel**:
A named, persistent discussion space in Picord, presented to users with a `#` prefix and serving as a dedicated venue for agent workflows, schedules, and cross-channel collaboration.
_Avoid_: Room, topic, group chat, session channel.

**Channel Name**:
A unique, lowercased, hyphen-separated string identifier for a channel without the `#` prefix (e.g. `smalltalk`, `zk-review`).
_Avoid_: Title, label, slug.

**Channel Manager**:
The core backend subsystem responsible for channel lookup, uniqueness enforcement, lifecycle, and cross-channel message routing.
_Avoid_: Session manager, post office, router.

**Channel Post**:
An asynchronous message dispatched from one channel's agent directly into another channel, attributed to the session owner with origin context.
_Avoid_: Mailbox, cross-session send, relay.

**Channel Origin**:
The contextual tag (`via #source-channel`) attached to a channel post, identifying the originating channel for attribution and reciprocal receipts.
_Avoid_: Referrer, source header.

## Connection Engine

**Event Connection**:
The deep client-side networking engine responsible for managing long-lived communication (Server-Sent Events and Long Polling fallback) with the Picord backend.
_Avoid_: Socket manager, event source wrapper, poll driver.

**Connection Status**:
The four-state lifecycle condition of the event connection: `"connecting"`, `"open"`, `"stale"`, or `"closed"`.
_Avoid_: Net state, ready state, socket state.

**Silent Socket**:
A half-open or suspended TCP/TLS connection that has ceased receiving server heartbeats without raising a native error event (typically occurring after mobile OS sleep).
_Avoid_: Dead socket, frozen pipe, ghost connection.

**Heartbeat Probe**:
The watchdog mechanism measuring elapsed time since the last server ping against dual thresholds (1.5× for wake recovery, 2.5× for active watchdog timeout).
_Avoid_: Ping timer, keepalive checker, health loop.

**Session Switch**:
An in-band control operation allowing an established connection to switch active session context without terminating or re-establishing the underlying HTTP transport.
_Avoid_: Reconnect, channel jump, session reload.

## History Search

**History Search Engine**:
The decoupled server subsystem responsible for scanning, filtering, and excerpting transcript messages across sessions and channels.
_Avoid_: Full-text database, grep worker, log scanner.

**Search Scope**:
The target partition of conversations queried during a search, supporting `"current"`, `"all"`, `"#channel-name"`, `"channels"`, `"chats"`, or numeric conversation IDs.
_Avoid_: Query filter, session category, target range.

**Incremental Entry Cache**:
An in-memory index caching parsed entry words up to a recorded `lastIndexedEntryId`, querying only newly committed entries on subsequent searches.
_Avoid_: Shadow database, message cache, dump buffer.

**Transcript Excerpt**:
A trimmed text snippet surrounding a matched search keyword, displaying relative timestamps, stable entry IDs, and originating channel labels.
_Avoid_: Log line, match snippet, summary clip.

## Quote & Mention Provenance

**Quote Provenance**:
The structured origin metadata associated with a quoted passage, identifying its originating session ID, channel name, entry ID, and author.
_Avoid_: Quote link, message ref, citation.

**Quote Origin**:
The coordinate referencing an exact source turn within a session or channel (e.g. `#general` entry 42), enabling bidirectional navigation.
_Avoid_: Message URL, turn pointer, backlink coordinate.

**Context Block (Quote)**:
The server-injected `<pocket-context quote ...>` structure that provides the agent model with verified origin coordinates while leaving human transcript text as clean Markdown.
_Avoid_: System prompt injection, prompt wrapper, invisible quote.

**Jump-to-Source**:
The client-side navigation capability that takes the user directly to the original quoted message across sessions or channels upon clicking a quote origin capsule.
_Avoid_: Deep link, scroll jump, backlink hop.

## Authentication & Registration

**Password Authentication**:
The credential verification subsystem verifying usernames and passwords against scrypt-derived password hashes stored in `config.json`, without altering underlying cookie session mechanisms.
_Avoid_: Token auth, magic link login, passwordless session.

**Invite Registration**:
The onboarding workflow requiring an authorized invite code generated by administrator `John` to register new member accounts.
_Avoid_: Open sign-up, public registration, guest join.

**Password Hash**:
A secure cryptographic representation of a user password formatted as `scrypt$salt$derivedKey`, computed using Node.js's native `crypto.scrypt` with random 16-byte salts.
_Avoid_: MD5 hash, raw token, plain password.

**Picord Brand Icon**:
The bespoke visual symbol featuring a faceted, high-tech "P" glyph with channel grid elements, replacing the upstream `π` character across SVG and PWA assets.
_Avoid_: Pi icon, math logo, default favicon.
