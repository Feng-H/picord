# Picord 重大演进历史（Milestone History）

记录 `Picord`（`Feng-H/picord`）自基于 `TannerMidd/pi-pocket` 独立分叉以来的**重大能力与架构里程碑**，聚焦宏观演进脉络与关键取舍，不罗列零散修补提交。

---

## 2026-11-27 · 仓库深度瘦身、测试防线闭环与全套实测文档化

- **全仓测试清债与 CI 正式接管**：将服务端全量非浏览器测试（`npm run test:server`）接进 GitHub Actions `CI`，顺带定位并修复了 `pi-durable 1.6.0` 下休眠子代理重复巡检（`sleeping` 状态遗漏）及快捷键面板群聊管理入口缺失两个真实问题。
- **独立品牌彻底落地（`picord`）**：将系统服务（`picord.service` / `picord@.service`）、命令行入口（`bin/picord.js`）、默认数据目录（`~/.picord/`）与线上宣传页、文档站 URL 全面从历史命名切换为 `picord`。
- **仓库与线上文档精简重构**：清理了上游遗留的 Windows / macOS 桌面安装包、Nix 构建脚本、每周五上游发版说明与废弃草稿，补齐差异对照、全保留功能探索与模拟登录实测手册。

## 2026-11-27 · 隐私隔离改造（方案 B）与规则引擎交互闭环

- **默认私有隔离与共享群组（ADR-0009 / Spec 0012）**：改变上游“登录即共享全部会话”的模型——所有人建的对话和 `#频道` 默认仅自己可见；只有创建者通过 Share 面板主动勾选成员或发放单会话邀请链接时，才升级为共享群组。
- **规则引擎面板联动闭环**：投影进日程面板的静默规则任务支持直接编辑静默时长/提示词、暂停/恢复并持久化状态、单独取消，并确保只捕获真人发言、隔离各频道计时与消息。

## 2026-11-26 · 合并上游 v0.30.1 与三处核心深模块重构

- **同步上游 `v0.30.1` 与 `pi-durable 1.6.0`**：吸收归档会话彻底清理、产物多版本删除、工作区与模型策略增强等上游新能力，经实测评估暂锁 `pi-durable 1.6.0` 以维持生产稳定。
- **深模块架构解耦（Spec 0007 / 0008 / 0010）**：抽离 `TurnPipeline`（统一命令解析、转向打断权限与发送入口）、`DialogueRuntime`（解耦对话生命周期协调器）与深化的 `web/voice.js`，降低服务端核心文件的耦合度。
- **移动端 PWA 语音对讲体验升级**：完成按住说话（Push-to-Talk）、屏幕常亮锁、上滑取消手势与网络重连自愈机制。

## 2026-11-24 ~ 11-25 · 声明式规则引擎与身份安全体系上线

- **声明式对话规则引擎（ADR-0007）**：将早先靠模型提醒驱动的 `#smalltalk` 总结机制，升级为服务端确定性规则引擎——按无发言静默倒计时、热加载规则文件（`.dialogue-session/rules.json`）、自动跨频道投递与环境变更通知。
- **账号密码体系与独立品牌确立（ADR-0006）**：引入用户名/密码登录、邀请码注册与未登录统一重定向 `/login`，摆脱纯一次性链接的局限；启用全新 Picord 品牌图标与动态主题色彩响应。
- **断线自愈、长对话检索与跨频道引用（ADR-0001 ~ 0005）**：抽离强韧事件重连引擎（`EventConnection`）、频道优先历史检索（`HistorySearchEngine` / `search_history`）以及跨频道引用溯源（`QuoteProvenance`）。

## 2026-11-21 ~ 11-23 · 独立建仓：Discord 频道模式 + 语音转文字 + 中文化

- **去除外部聊天平台中继（Relay Removed）**：砍掉对 Telegram/Discord 等外部平台桥接的依赖，把 `#频道`、顶部置顶分组、输入框 `#` 引用和 `channel_post` 跨频道投递直接做进自托管网页/PWA 运行时。
- **语音直录转文字与中文界面**：接入服务端 Groq Whisper 语音转文字（`/api/stt`）与断网自动重传；上线全界面中文化与中英一键切换。
- **工程基线建立**：更名为 `Picord`，建立 GitHub Actions `CI` 检查与 `Pages` 文档站自动发布流水线。
